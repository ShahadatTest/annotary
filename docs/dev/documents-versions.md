- **API** (`server/docs.rs` has the route table): `GET /api/v1/vaults`; `POST /api/v1/blobs/check {hashes}` → `{lacking}`, `PUT /api/v1/blobs/{hash}` raw bytes, `GET /api/v1/blobs/{hash}`; `GET/POST /api/v1/docs`, `GET /api/v1/docs/resolve?doc=&vault=&deleted=`, `GET/DELETE /api/v1/docs/{id}`, `POST …/restore` / `…/purge`, `GET/POST …/versions`, `GET …/versions/{n}`, `GET …/status`, `GET …/sidecar?version=N` (canonical text). `doc_json` carries `action: null`, `open_threads: 0`, `mentions_me: 0`, `available_actions` (Vault defaults) — 04/05 fill them; `list` already accepts `action=` / `mentions_me=`; commit bodies already accept `placements`, `renderer`, `html_hash`, `actions_available` (05 stores it). `ApiError.extra` merges extra JSON fields into an error body (`candidates` on `ambiguous`, `what`/`size`/`max` on `too_large`).
- **Sidecar projection**: `server/sidecar.rs::build(store, doc, base_version)` — `assets` = the base Version's manifest (`assets_of`); add `threads` (04), per-Document `actions` (05). The CLI writes it via `annotary_sidecar::emit` (`cli/push.rs::write_sidecar`); push and pull both refresh it so `base_version` is what is on disk. CMD-5: after a Vault rename the Sidecar's `vault` is stale until that refresh; nothing reads it for an existing Document (push binds by `id`), no verb scans directories for Sidecars, and the read-only verbs (`show`, `status`) never write one.
- **CLI push flow** (`cli/push.rs`): hash → Markdown cap → asset scan (`assets::scan_document`; `--strict` fails here) → Asset caps → `blobs/check` with the manifest → `assets:` line → upload lacking (files re-read and re-verified, derivatives from memory) → commit (create or `…/versions`) → fetch Sidecar → write. 07 adds placements (`reanchor_for` before `blobs/check`), 09 the render, in the same commit body; ticket 17 (replacing 16's `--strict` rule): with `base_version < head` and content ≠ head, the containment check runs on the head `head_of` read, before the re-anchoring line / any upload — missing ⇒ exit 5 `head_moved` with the diff, contained ⇒ `contains_head` in the commit, `--discard-head-changes` ⇒ a warning and `discard_head_changes`. `--doc` accepts any DOC form. `pull` (`cli/pull.rs`) verifies the blob hash and refuses over local edits via `Binding::matches_base` (03 extends the identity with `assets[]` for free — `Binding.base_assets`).
